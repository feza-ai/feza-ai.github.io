# Acquisition website positioning

Updated 2026-09-30 at the owner's request to market Feza, Inc. for acquisition.

## Evidence and editorial decisions

- Wolf README and current design document replace historical performance claims as the source of truth. No sustainable edge is established; no live trading is authorized. Existing components are distinguished from the autonomous workflow roadmap. Removed unsupported accuracy, five-year validation, deployment readiness, test counts, and speculative decade-long targets.
- Zerfoo README documents Go inference, training, serving, GGUF loading, GPU acceleration, tabular ML and forecasting. Its Apache 2.0 license is explicit. No exclusive ownership or inclusion in a transaction is assumed.
- Position the opportunity as an existing technical foundation for a buyer to develop, rather than a validated profitable trading operation. No revenue, customer, valuation, corporate standing, or transferability claims were available.
- Retain the existing hello@feza.ai contact. Inquiry links open email with an acquisition subject. Price, transaction structure, included assets, IP rights and transition support remain discussion topics pending owner input.

## Design

White #ffffff, ink #152338, blue #1649db, pale blue #edf3fd, navy #142b57 and line #d9e2ef. Manrope carries the display and text hierarchy. An asymmetric hero pairs the acquisition message with a technology map; product details and development status follow. The dark opportunity section separates possible buyer directions from documented capabilities. Native disclosure elements support diligence questions without JavaScript.

No deployment or external outreach performed.
